# ritmelli-releases

As versões da Vitrola: o instalador, a atualização parcial e o manifesto que o app instalado
consulta para saber se há versão nova. Baixe o `Vitrola-<versão>-setup.exe` da
[versão mais recente](https://github.com/ritmelli/ritmelli-releases/releases/latest).

- **Código-fonte:** [ritmelli/ritmelli](https://github.com/ritmelli/ritmelli) (GPLv3). Cada
  versão tem lá a tag com o número dela, e a página de cada versão aqui leva o link.
- **Como é montada:** pela esteira pública do próprio repo do código
  (`.github/workflows/monta.yml`), numa máquina do GitHub.
- **Code signing policy:** [a política de assinatura de código](https://github.com/ritmelli/ritmelli#code-signing-policy).
